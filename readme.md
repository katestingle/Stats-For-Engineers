# STAT3310: Probability and Statistics

This repository contains a collection of Python exercises and sample programs used to study fundamental probability theory and common statistical distributions.

The material is organized by lecture/topic and focuses on interactive calculations, visualizations, and distribution-based examples using Python libraries such as NumPy, SciPy, and Matplotlib.

## Contents

- `Lec 1 & 2 - Probability Theory`
  - Introductory probability concepts
  - Permutations and combinations
- `Lec 3 - Discrete Random Variables and Probability Distributions`
  - Random variables
  - Discrete distribution calculations
- `Lec 4 - Commonly Used Discrete Probability Distributions`
  - Bernoulli
  - Binomial
  - Poisson
- `Lec 7 Commonly Used Continuous Probability Distributions`
  - Uniform
  - Exponential
  - Normal

## Setup

This project uses Python 3 and the following packages:

- `numpy`
- `scipy`
- `matplotlib`

Install dependencies with:

```bash
pip install numpy scipy matplotlib
```

## Running the scripts

From the project root, run any script directly with Python. For example:

```bash
python "Lec 4 - Commonly Used Discrete Probability Distributions/binomial_distribution.py"
```

## Learning goals

This repository is intended to help with understanding:

- probability rules and counting methods
- discrete and continuous random variables
- probability mass and density functions
- cumulative distribution functions
- expectation, variance, and distribution behavior
- simulation and plotting of statistical distributions

## Notes

These scripts are primarily educational and designed for learning, experimentation, and course assignments. They are not a packaged application or library.
